# Métriques de Courier (export PDF du scénario)

Fichiers AFM des polices Courier, Courier-Bold, Courier-Oblique et
Courier-BoldOblique, publiés par Adobe Systems avec les quatorze polices
standard du PDF. Ils ne contiennent que les largeurs des caractères : la
police elle-même fait partie de tout lecteur PDF, rien n'est embarqué.

Leur licence (en tête de chaque fichier) permet de les copier et de les
distribuer librement, avec leur mention de copyright. Copie de
`@foliojs-fork/pdfkit/js/data/` (dépendance de pdfmake).
